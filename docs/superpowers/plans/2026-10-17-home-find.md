# Home search, sort and pin: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Home gets, at the top of its list, a search field ("Search projects") and a sort button (sheet "Sort by": Last edited / Date created / Name / Length, remembered on the phone), shown from 6 projects or while a search is typed; projects can be pinned from the actions sheet (Pin / Unpin), and pinned ones show first under "Pinned", the rest under the sort's name, with a small pin mark on the card.

**Architecture:** Order and match are PURE (`src/projects/homeOrder.ts`: fold, natural name order, the four sorts with stable ties, pinned split, rows of two with headings). Pins and the sort are ONE phone preference in the synchronous `localStorage` (`src/projects/homePrefs.ts`, key `clipy.home.v1`, versioned; damaged / newer = defaults; newer never overwritten) — never project data, so pinning writes no `project.json`, moves no `updatedAt` and keeps the undo history's stamp. A hook (`useHomeFind`) joins the list, the prefs and the query; Home's `FlatList` draws `homeRows` (one column of rows, each row two 50 % cells — the same grid) with the find row as its `ListHeaderComponent`, so the header, the glass pill and the bottom actions are untouched.

**Tech Stack:** Expo SDK 57, React Native (Fabric), TypeScript strict, Jest 29.7 (`jest-expo`) + RNTL 14. No native code, no new package, no `app.json` change, no schema bump.

**Spec:** `docs/superpowers/specs/2026-10-17-home-find-design.md` (binding: §2.1 the preference, §2.2 the order and the fold, §2.3 the screen).

```ts
import { FIND_WORDS } from "./homeFindWords";

/**
 * Home's order and search, PURE (no React, no Expo). The spec's §2.2: what each sort reads, the stable ties, the fold that makes case
 * and accents not matter (also for Arabic, Persian and Hebrew — a hand-written table, no `\p{…}`), and the rows the list draws.
 * The name order is our own and deterministic (folded text, digit runs by value, everything else by UTF-16 code unit), NOT
 * Intl.Collator: Hermes' collation on iOS cannot be pinned by a Jest vector, this can.
 */
export type HomeSort = "edited" | "created" | "name" | "length";
export const HOME_SORTS: readonly HomeSort[] = ["edited", "created", "name", "length"];
export const DEFAULT_SORT: HomeSort = "edited";
/** The search field and the sort button show from this many projects (or while a search is typed). */
export const FIND = { showAt: 6 } as const;
const SORT_TITLES: Record<HomeSort, string> = FIND_WORDS.sorts;

/** What the order reads of a listed project (`ProjectSummary` has all of it). */
export interface Orderable { id: string; name: string; durationSec: number; updatedAt: string; createdAt: string; broken: boolean }

/**
 * Code points a fold drops: combining diacritics, Hebrew points, Arabic marks (harakat, the dagger alef, Quranic marks — and so the
 * hamza / madda that NFD splits off أ إ آ ؤ ئ), the tatweel, ZWNJ / ZWJ, variation selectors. NOT the Indic / Thai vowel signs and
 * viramas: they are part of the word.
 */
const DROPPED: readonly (readonly [number, number])[] = [
  [0x0300, 0x036f], [0x0591, 0x05bd], [0x05bf, 0x05bf], [0x05c1, 0x05c2], [0x05c4, 0x05c5], [0x05c7, 0x05c7],
  [0x0610, 0x061a], [0x0640, 0x0640], [0x064b, 0x065f], [0x0670, 0x0670], [0x06d6, 0x06dc], [0x06df, 0x06e4], [0x06e7, 0x06e8], [0x06ea, 0x06ed],
  [0x1ab0, 0x1aff], [0x1dc0, 0x1dff], [0x200c, 0x200d], [0x20d0, 0x20ff], [0xfe00, 0xfe0f], [0xfe20, 0xfe2f],
];
const dropped = (c: number) => DROPPED.some(([lo, hi]) => c >= lo && c <= hi);
const FINAL_SIGMA = 0x03c2;

/** A name as the search and the name order see it: lower case, NFD, the marks above dropped, ς read as σ. */
export function foldName(s: string): string {
  let out = "";
  for (const ch of s.toLowerCase().normalize("NFD")) {
    const c = ch.codePointAt(0) as number;
    if (dropped(c)) continue;
    out += c === FINAL_SIGMA ? "σ" : ch;
  }
  return out;
}

/** The query trimmed and folded; empty matches everything; else a substring of the folded name. */
export function matchesQuery(name: string, query: string): boolean {
  const q = foldName(query.trim());
  return q === "" || foldName(name).includes(q);
}

const DIGITS = /([0-9]+)/;
function compareDigits(a: string, b: string): number {
  const x = a.replace(/^0+(?=.)/, ""), y = b.replace(/^0+(?=.)/, "");
  if (x.length !== y.length) return x.length - y.length;
  return x < y ? -1 : x > y ? 1 : 0;
}
/** A → Z on folded names: runs of ASCII digits by their value ("2" before "10", digits before letters), the rest by code unit; a prefix first. 0 = the same to the eye. */
export function compareNames(a: string, b: string): number {
  const xs = foldName(a).split(DIGITS), ys = foldName(b).split(DIGITS);
  const n = Math.min(xs.length, ys.length);
  for (let i = 0; i < n; i++) {
    const p = xs[i] as string, q = ys[i] as string;
    if (p === q) continue;
    if (i % 2 === 1) { const r = compareDigits(p, q); if (r !== 0) return r; continue; }
    return p < q ? -1 : 1;
  }
  return xs.length - ys.length;
}

/** A date that does not parse is the oldest. */
const time = (iso: string) => { const t = Date.parse(iso); return Number.isFinite(t) ? t : -Infinity; };
const desc = (a: number, b: number) => (a > b ? -1 : a < b ? 1 : 0);
const raw = (a: string, b: string) => (a < b ? -1 : a > b ? 1 : 0);
const BY: Record<HomeSort, (a: Orderable, b: Orderable) => number> = {
  edited: (a, b) => desc(time(a.updatedAt), time(b.updatedAt)),
  created: (a, b) => desc(time(a.createdAt), time(b.createdAt)),
  name: () => 0,
  length: (a, b) => desc(a.durationSec, b.durationSec),
};
/** Broken last (as the listing always had it), then the sort, then the folded name, the raw name, the id: one order whatever the listing's order. */
export function compareProjects(sort: HomeSort, a: Orderable, b: Orderable): number {
  return Number(a.broken) - Number(b.broken) || BY[sort](a, b) || compareNames(a.name, b.name) || raw(a.name, b.name) || raw(a.id, b.id);
}

export interface HomeOptions { sort: HomeSort; pins: readonly string[]; query: string }
/** The projects that match, in the sort's order, split: pinned (and not broken) first, all the others after. */
export function orderProjects<T extends Orderable>(list: readonly T[], o: HomeOptions): { pinned: T[]; rest: T[] } {
  const pins = new Set(o.pins);
  const shown = list.filter((p) => matchesQuery(p.name, o.query)).sort((a, b) => compareProjects(o.sort, a, b));
  return { pinned: shown.filter((p) => !p.broken && pins.has(p.id)), rest: shown.filter((p) => p.broken || !pins.has(p.id)) };
}

/** One row of Home's list: a small heading, or up to two cards side by side (each card's cell is 50 % — the grid as it always was). */
export type HomeRow<T> = { kind: "heading"; key: string; title: string } | { kind: "cards"; key: string; items: T[] };
function pairs<T extends { id: string }>(list: readonly T[]): HomeRow<T>[] {
  const out: HomeRow<T>[] = [];
  for (let i = 0; i < list.length; i += 2) {
    const items = list.slice(i, i + 2);
    out.push({ kind: "cards", key: `cards:${items.map((p) => p.id).join(",")}`, items });
  }
  return out;
}
/** Headings only while a pinned project is in view: "Pinned", then the sort's name over the rest (none over an empty rest). */
export function homeRows<T extends { id: string }>(order: { pinned: readonly T[]; rest: readonly T[] }, sort: HomeSort): HomeRow<T>[] {
  if (order.pinned.length === 0) return pairs(order.rest);
  const rows: HomeRow<T>[] = [{ kind: "heading", key: "heading:pinned", title: FIND_WORDS.pinned }, ...pairs(order.pinned)];
  if (order.rest.length > 0) rows.push({ kind: "heading", key: "heading:rest", title: SORT_TITLES[sort] }, ...pairs(order.rest));
  return rows;
}

/** The search row: from `FIND.showAt` projects (all listed, broken too), or while anything — even a space — is typed. */
export function showFind(count: number, query: string): boolean {
  return count >= FIND.showAt || query !== "";
}

/** The pins whose project is listed; THE SAME array when none is dropped (so nothing is written). */
export function keepListed(pins: readonly string[], ids: readonly string[]): readonly string[] {
  const here = new Set(ids);
  const kept = pins.filter((id) => here.has(id));
  return kept.length === pins.length ? pins : kept;
}
```

`src/projects/homePrefs.ts`:

```ts
import "expo-sqlite/localStorage/install";
import { DEFAULT_SORT, HOME_SORTS, type HomeSort } from "./homeOrder";

/**
 * The one key of Home's sort and pins, in the same synchronous localStorage as `src/auth/welcomeSeen.ts` (so Home's first render
 * already has them). A preference of THIS phone, never project data: pinning must not write project.json — that would change its
 * stamp and drop the project's kept undo history, move it in "Last edited" and cost a turn of its chain. Nothing outside this file
 * reads or writes the key.
 */
export const HOME_PREFS_KEY = "clipy.home.v1";
export const HOME_PREFS = { version: 1, idMax: 64 } as const;
/** `pins`: a SET of project ids (their order means nothing on screen). No limit: Home drops a pin as soon as its project is not listed. */
export interface HomePrefs { sort: HomeSort; pins: readonly string[] }
const defaults = (): HomePrefs => ({ sort: DEFAULT_SORT, pins: [] });

type Stored = { kind: "none" | "damaged" | "newer" } | { kind: "ok"; prefs: HomePrefs };

function cleanPins(v: unknown): string[] {
  if (!Array.isArray(v)) return [];
  const out: string[] = [];
  for (const id of v) if (typeof id === "string" && id.length > 0 && id.length <= HOME_PREFS.idMax && !out.includes(id)) out.push(id);
  return out;
}

/** The VERSION is read before the shape: newer = a newer Clipy's, kept as it is; damaged = anything without a whole version ≥ 1. */
function readStored(): Stored {
  let raw: string | null;
  try { raw = localStorage.getItem(HOME_PREFS_KEY); } catch { return { kind: "none" }; }
  if (raw === null) return { kind: "none" };
  let v: unknown;
  try { v = JSON.parse(raw); } catch { return { kind: "damaged" }; }
  if (typeof v !== "object" || v === null || Array.isArray(v)) return { kind: "damaged" };
  const { version, sort, pins } = v as { version?: unknown; sort?: unknown; pins?: unknown };
  if (typeof version !== "number" || !Number.isInteger(version) || version < 1) return { kind: "damaged" };
  if (version > HOME_PREFS.version) return { kind: "newer" };
  const known = (HOME_SORTS as readonly unknown[]).includes(sort);
  return { kind: "ok", prefs: { sort: known ? (sort as HomeSort) : DEFAULT_SORT, pins: cleanPins(pins) } };
}

/** The stored sort and pins; nothing, junk, a newer value or storage that fails → Last edited and no pins. Never throws. */
export function loadHomePrefs(): HomePrefs {
  const s = readStored();
  return s.kind === "ok" ? s.prefs : defaults();
}

/** Writes them as version 1 — unless a newer Clipy's value is there (kept as it is; false). A damaged value is simply replaced. Never throws. */
export function saveHomePrefs(prefs: HomePrefs): boolean {
  if (readStored().kind === "newer") return false;
  try {
    localStorage.setItem(HOME_PREFS_KEY, JSON.stringify({ version: HOME_PREFS.version, sort: prefs.sort, pins: [...prefs.pins] }));
    return true;
  } catch { return false; }
}
```

`src/projects/useHomeFind.ts`:

```ts
import { useEffect, useMemo, useRef, useState } from "react";
import { homeRows, keepListed, orderProjects, showFind, type HomeSort } from "./homeOrder";
import { loadHomePrefs, saveHomePrefs, type HomePrefs } from "./homePrefs";
import type { ProjectSummary } from "./storage";

/**
 * Home's search, sort and pins: the listed projects + the phone's preference (homePrefs.ts) + the typed query → the rows the list
 * draws. The query is memory only (kept while Home is mounted). Every change of the sort or a pin is written at once; nothing here
 * ever touches a project. `listed`: pins whose project is not in the listing are dropped only once a listing has come back.
 */
export function useHomeFind(projects: readonly ProjectSummary[], listed: boolean) {
  const [prefs, setPrefs] = useState<HomePrefs>(loadHomePrefs);
  const [query, setQuery] = useState("");
  const now = useRef(prefs);   // the latest value, for two changes in one tap
  const change = (next: HomePrefs) => { now.current = next; setPrefs(next); saveHomePrefs(next); };

  useEffect(() => {
    if (!listed) return;
    const kept = keepListed(now.current.pins, projects.map((p) => p.id));
    if (kept !== now.current.pins) change({ ...now.current, pins: kept });
  }, [projects, listed]);

  const order = useMemo(() => orderProjects(projects, { sort: prefs.sort, pins: prefs.pins, query }), [projects, prefs, query]);
  const rows = useMemo(() => homeRows(order, prefs.sort), [order, prefs.sort]);
  const pinned = useMemo(() => new Set(prefs.pins), [prefs.pins]);
  const shownCount = order.pinned.length + order.rest.length;

  return {
    query, setQuery, clearQuery: () => setQuery(""),
    sort: prefs.sort,
    setSort: (sort: HomeSort) => { if (sort !== now.current.sort) change({ ...now.current, sort }); },
    isPinned: (id: string) => pinned.has(id),
    togglePin: (id: string) => {
      const pins = now.current.pins;
      change({ ...now.current, pins: pins.includes(id) ? pins.filter((x) => x !== id) : [...pins, id] });
    },
    unpin: (id: string) => { if (now.current.pins.includes(id)) change({ ...now.current, pins: now.current.pins.filter((x) => x !== id) }); },
    rows,
    showFind: showFind(projects.length, query),
    /** A query is typed and nothing matches (there ARE projects: no projects at all is Home's own empty state). */
    noMatch: projects.length > 0 && shownCount === 0,
  };
}
```

Note on `isPinned` in `togglePin`: it reads `now.current`, not the render's `pinned`, so two calls in one tap see each other.

```markdown
## O. Search, sort and pin on Home

### 67. The search box
With 6 or more projects, look at the top of the list on Home.
- **Right looks like:** a box "Search projects" with a magnifier, and a sort button beside it; both move up with the cards when
  you scroll. The round buttons at the top right and the two buttons at the bottom are exactly where they were. With 5 or fewer
  projects there is no box.
- **Wrong looks like:** the box stays put over the cards, or covers the title "Projects".

### 68. Typing
Tap the box and type part of a name, without its accents or capitals (for "Été à Nice", type "ete").
- **Right looks like:** the cards narrow down with every letter, and the keyboard stays up while you type. Type something no
  project has: "No projects match" and Clear Search, which brings everything back. Scroll the list: the keyboard goes down.
  With the keyboard up, tap a card once: the project opens.
- **Wrong looks like:** the keyboard closing after each letter, or needing two taps on a card.

### 69. Arabic names
Rename a project to an Arabic name with vowel marks or a hamza (for example "أَحْمَد"), then search for it typed plainly ("احمد").
- **Right looks like:** it is found. Write down any name you expected to find and did not.

### 70. Sort by
Tap the sort button.
- **Right looks like:** "Sort by" with Last edited ticked; tap Name — the sheet closes and the cards are A to Z, with "Project 2"
  before "Project 10". Close Clipy completely and open it again: still by name. Try Date created and Length too.

### 71. Pin
Touch and hold a project → **Pin** (the first button).
- **Right looks like:** the project moves to the top under a small heading "Pinned", with a small pin on its picture; the others
  are under "Last edited" (or the sort you chose). Its "Edited" line does NOT change. Open it, press Undo — your old steps are
  still there (pinning did not touch the project). Hold it again → **Unpin**: the headings go.
- **Wrong looks like:** the project's edited time changes, or Undo has nothing after pinning.

### 72. Pinned and deleted, duplicated
Pin a project, Duplicate it, then delete the original.
- **Right looks like:** the copy is not pinned; after the delete there is no "Pinned" heading left.

### 73. Light and large text
Set the iPhone to Light (Settings → Display & Brightness), then Larger Text at the largest standard size.
- **Right looks like:** the box, the headings and the Sort by sheet are cream with dark words; the typed text gets bigger but
  stays inside the box; a long project name still ends in dots.
```
