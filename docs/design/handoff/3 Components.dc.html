Every component from brief 5.4 plus the new ones, in dark (4a) and light (4b). States are left to right: default, pressed, selected/on, disabled, busy, error, wherever the component has them. Components marked system are the real iOS control; the drawing only shows how Clipy tints and labels it.

Inconsistencies resolved
Tool button and Tile become one “Tool tile”. The toolbar uses its bare form (symbol over label). Strips use its boxed form (picture, symbol or shape in a concentric box, with the label under it).
One text field. A visible label above, 12-pt inner padding, a Clear button, and the message line under it. Number fields are the same field at compact width with a unit suffix.
One destructive form. In menus, lists and alerts: the system destructive role (red text). In panels: a grey-filled capsule with a red label and symbol. “Sign out” is destructive too.
One home for the primary action. The bottom of the screen, sheet or panel, full width or trailing. In the editor it is Export in the navigation bar. In strips and panels there is none; Done is a plain circle.
One pick-one system. Boxed tool tiles that show the result (thumbnails, drawn shapes, speed charts). Segmented controls for tabs and two to five text options. Colour swatches stay round because the colour is the content, now at 44 pt.
One format per unit. Percent “100%” · seconds with decimals matching the step (“0.5 s”, “0.50 s”, “2 s”) · speed “1.5×” · signed values “+25”, “−10”, “0” · plain numbers “70” · time “0:07”. Always tabular digits.
