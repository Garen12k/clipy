T1
The gold rule
Gold fill marks the one action that completes the current screen or sheet and moves on. One per screen at most: Export (editor header), Create (Aspect ratio), Choose Photos and Videos (Quick edit), Get Started / Continue (wizard), Send Code and Sign In (sign-in), Post (Post), Post to… (Export done), Start Editing.
Nothing inside a strip or a panel is gold. Each panel’s main action (Transcribe, Replace, Try Again, Open Settings, Tap, Choose a File, Read Aloud, Save to Photos, Trim’s Apply) is filled in the label colour; the rest are grey. Done is a grey circle. Gold appears there only as an accent ink: selection rings, slider fills, progress, text actions.
Never gold: Apple’s sign-in button (Apple’s own black or white), destructive actions (red label on grey), and Accounts, which has no primary action. Light appearance: gold fill keeps #D9B36A with #1A1408 text (8.9 : 1). Every gold line, ring, value and status symbol uses the ink #8B5F00 (5.9 : 1 on white).
